# 🌤️ Simple Weather App

Projeto de estudo focado na construção de uma aplicação moderna de previsão do tempo, criado com o objetivo de dominar integração com APIs, gerenciamento de estado assíncrono e boas práticas de arquitetura frontend.

---

## 🚀 Funcionalidades

O projeto conta com os seguintes recursos principais:

- 🔎 **Busca de Localidades**: Pesquise cidades do mundo inteiro com preenchimento inteligente.
- 🌡️ **Condições Atuais**: Exibição em tempo real de temperatura, umidade, vento e sensação térmica.
- 🕒 **Previsão Horária**: Linha do tempo mostrando as variações do clima para as próximas horas.
- 📅 **Previsão Estendida**: Tendência detalhada do tempo para os próximos 10 dias.
- ⚠️ **Alertas Locais**: Avisos meteorológicos e dados de estações próximas da região.

---

## 🎯 Objetivos de Aprendizado

Este projeto serve como laboratório prático para consolidar conceitos avançados de engenharia de software frontend:

- **Integração Absoluta**: Consumir dados assíncronos e blindar o app contra falhas de rede.
- **Arquitetura Limpa**: Dividir responsabilidades de código entre o que é visual e o que é lógica.
- **Profissionalismo**: Praticar _System Design_ e manter um histórico de commits profissional seguindo convenções (ex: _Conventional Commits_).

---

## 🏆 Mapa de Competências

Ao finalizar o desenvolvimento, as seguintes habilidades serão consolidadas:

| Competência        | Descrição                                      |
| :----------------- | :--------------------------------------------- |
| **HTTP/API**       | Request, response, status codes, headers, JSON |
| **Async**          | Promise, async/await, estados assíncronos      |
| **React**          | Estado, efeitos, composição e fluxo de dados   |
| **TypeScript**     | Modelagem da resposta externa sem `any`        |
| **UX**             | Loading, vazio, erro, retry                    |
| **Performance**    | Debounce, cache, cancelamento                  |
| **Arquitetura**    | Separar UI, lógica e acesso a dados            |
| **Testes**         | Testar comportamento sem depender da API real  |
| **Acessibilidade** | `aria-live` e comunicação de estados           |
| **DevTools**       | Network, requests duplicadas, timing e erros   |
| **TanStack Query** | Cache, retry, stale data, invalidação          |
